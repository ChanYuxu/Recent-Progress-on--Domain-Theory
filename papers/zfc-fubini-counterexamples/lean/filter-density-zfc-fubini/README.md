# Filter-density ZFC Fubini counterexample

This standalone Lean 4 project formalizes the counterexample built from the density topology on the circle and a dcpo of filters.

## Build

```sh
lake build
```

The project pins Lean `v4.30.0-rc2` and the matching Mathlib release in `lake-manifest.json`.

## Main files

- `ZFCFubini.lean` imports the complete development.
- `ZFCFubini/` contains the mathematical modules.
- `SOURCE-MATCH.md` records the source-version boundary.
- `VERIFICATION.md` summarizes the machine evidence and its limits.

Paper TeX sources are intentionally not included. The article provides the revised PDF, while `SOURCE-MATCH.md` records the hashes and lengths of the private manuscript snapshots used for the audit.

The initial counterexample construction and proof were generated by ChatGPT. The manuscript was subsequently checked and revised, and the Lean 4 development was produced with AI assistance.
